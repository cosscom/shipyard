# Canvas

A built-in Shipyard plugin that gives each worktree a spatial workspace. Choose a board, then pick any source worktree to add live conversations, terminals, read-only subagent conversations, or browser previews. Every node shows its source. Start a terminal, drag, resize, pan, zoom, and make visual links between nodes. Layouts are stored locally by board worktree. Opening a node in the usual workspace is one click away.

Subagents connect to their parent automatically. Other links are visual references you can add between nodes; they do not send prompts or commands between sessions.

Use **Add node** or right click empty canvas to open the searchable node picker. Choose its source worktree there. Two-finger scrolling pans empty canvas; pinch or Ctrl/⌘-scroll zooms around the pointer. Drag with the middle mouse button or hold Space while dragging to pan over nodes. The zoom controls and board picker stay in the canvas corners.
